# Node.js Backend

## Purpose

This folder will contain the locally hosted Node.js backend for the IoT smart-home security system.

## Planned Responsibilities

The backend is planned to:

* Receive security events from the ESP32-S3-EYE.
* Process security-event information.
* Store information using SQLite.
* Provide API endpoints for the Flutter mobile application.
* Handle authentication and protected resources.
* Support synchronization between the mobile application and backend.

## Planned Technology

* Node.js
* SQLite
* HTTP API

## Current Status

The backend has not yet been implemented.

The backend architecture and API design will be developed during the system-design phase.
