# Flutter Mobile Application

## Purpose

This folder will contain the Flutter mobile application for monitoring the IoT smart-home security system.

## Planned Responsibilities

The application is planned to:

* Authenticate users.
* Display security events.
* Display captured images.
* Provide access to locally available information while offline.
* Synchronize information after connectivity is restored.
* Provide a user interface for monitoring the security system.

## Planned Technology

* Flutter
* Dart

## Current Status

The Flutter mobile application has not yet been implemented.

The mobile interface and communication requirements will be designed during the system-design phase.
