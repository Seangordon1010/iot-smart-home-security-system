# Database Design

## Status

The SQLite database structure has not yet been finalized.

The database design will be developed during the system architecture and design phase.

## Planned Database

The project will use SQLite as the local database for the Node.js backend.

## Planned Data

The database is expected to contain information related to:

* Users.
* Authentication.
* Security events.
* Captured images or image references.
* Event timestamps.
* Synchronization status.

## Planned Documentation

The completed database documentation will include:

* Table names.
* Columns.
* Data types.
* Primary keys.
* Foreign keys where applicable.
* Relationships between tables.
* Indexes where appropriate.
* Data retention considerations.

A database diagram will be added after the database structure has been designed.
