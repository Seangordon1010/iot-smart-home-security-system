# ESP32-S3-EYE

## Purpose

This folder will contain the ESP32-S3-EYE code used by the IoT smart-home security system.

## Hardware

The project uses an ESP32-S3-EYE development board.

## Planned Functionality

The ESP32-S3-EYE portion of the system is planned to:

* Detect security events.
* Capture images.
* Connect to the local Wi-Fi network.
* Communicate security-event information to the Node.js backend.

## Initial Hardware Testing

Initial hardware testing was performed using official ESP32 example code.

The purpose of this testing was to verify that:

* The development environment could communicate with the ESP32-S3-EYE.
* Code could be compiled for the board.
* Code could be uploaded to the board.
* The development board could successfully run ESP32 code.

The example code used for initial hardware verification is not apart of the project's custom implementation, just used to initialize the development board.

## Project Code

Project-specific ESP32 code will be added to this directory during the implementation phase.
